## 🎯 GUIDE ÉTAPE PAR ÉTAPE

### 1️⃣ Créer un compte GitHub

1. Allez sur : https://github.com/signup
2. Créez votre compte (gratuit)
3. Confirmez votre email

### 2️⃣ Créer un nouveau repository

1. Cliquez sur le bouton **"+"** en haut à droite
2. Sélectionnez **"New repository"**
3. Remplissez :
   - **Repository name** : `bamsgo`
   - **Description** : `Marketplace de services et locations à Kolwezi`
   - ✅ Cochez **"Public"**
   - ✅ Cochez **"Add a README file"**
4. Cliquez **"Create repository"**

### 3️⃣ Uploader vos fichiers

1. Dans votre repository, cliquez sur **"Add file"**
2. Sélectionnez **"Upload files"**
3. **Glissez-déposez** ou sélectionnez ces fichiers :
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `README.md` (optionnel)
   - `GUIDE-RAPIDE.md` (optionnel)
4. Dans le champ en bas, écrivez : "Initial commit - BamsGo v1.0"
5. Cliquez **"Commit changes"**

### 4️⃣ Activer GitHub Pages

1. Cliquez sur **"Settings"** (onglet en haut)
2. Dans le menu de gauche, cliquez sur **"Pages"**
3. Sous **"Source"**, sélectionnez **"main"** (ou "master")
4. Cliquez **"Save"**
5. Attendez 1-2 minutes ⏳
6. Rafraîchissez la page
7. Vous verrez un message vert :
   ```
   Your site is published at https://votre-nom.github.io/bamsgo
   ```

## ⚠️ NOTES IMPORTANTES

### Icônes manquantes
Vous verrez des erreurs dans la console concernant les icônes (icon-192.png, etc.).
**C'est normal !** L'application fonctionne quand même.

Pour ajouter les icônes plus tard :
1. Créez-les sur Canva (512x512px, fond orange #E85D04)
2. Redimensionnez en 192px et 512px minimum
3. Sur GitHub : "Add file" → "Upload files"
4. Uploadez `icon-192.png` et `icon-512.png`

### Modifications futures
Pour modifier votre site :
1. Allez dans votre repository
2. Cliquez sur le fichier à modifier
3. Cliquez sur l'icône crayon (Edit)
4. Faites vos modifications
5. Cliquez "Commit changes"
6. Attendez 1-2 minutes pour voir les changements

## 🆘 PROBLÈMES COURANTS

### ❌ "404 - File not found"
→ Vérifiez que vous avez bien uploadé `index.html` (pas bamsgo-complete.html)
→ Attendez 2-3 minutes après avoir activé GitHub Pages

### ❌ "Your site is not published yet"
→ Attendez quelques minutes
→ Rafraîchissez la page Settings → Pages

### ❌ "Site doesn't work on mobile"
→ Vérifiez que vous utilisez HTTPS (pas HTTP)
→ Le lien GitHub Pages est automatiquement en HTTPS ✅

### ❌ "Can't install the app"
→ Normal sans les icônes
→ L'app fonctionne quand même dans le navigateur
